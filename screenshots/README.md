# Screenshots

Drop the following images here (PNG). The main `README.md` references these exact
filenames — once a file lands here and is pushed, it appears automatically.

| File | What to capture |
|---|---|
| `logo.png` | A small square logo/avatar for Kairos (~256px). Optional — remove the `<img>` line at the top of the README if you skip it. |
| `01-telegram.png` | A Telegram conversation with the bot — a real request and its reply, ideally one that shows it remembering something about you. |
| `02-cli-console.png` | The terminal console after `startKairos`, mid-goal, showing it narrating steps (and the `/status` output looks great here too). |
| `03-browser.png` | The controlled browser window while Kairos is acting on a page — e.g. a search results page or a form it filled. Crop to the browser. |
| `04-desktop.png` | Kairos working inside a native Windows app — Notepad with a note it typed, or the Calculator showing a result it read back. |

Optional extra you can add later (then add a row to the README's screenshot table):

| File | What to capture |
|---|---|
| `05-voice.png` | The console during a voice session — the room-calibration / "listening…" line, or a spoken exchange. |

**Tips**
- Terminal shots: dark theme, crop tight, make sure the narrated steps are readable.
- Browser/desktop shots: capture the real window so it's clearly your machine, not a mockup.
- Aim for ~1400–1600px wide for the app shots; natural size is fine for terminal shots.
